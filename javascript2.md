## 1. Преобразование типов

В JavaScript существует три ключевых типа преобразования: строковое, численное и логическое.

* **Строковое (`String`)**: активируется, когда требуется текстовое представление значения (например, при вызове `alert(value)`).
* **Численное (`Number`)**: происходит автоматически в математических выражениях и функциях.
* **Логическое (`Boolean`)**: возникает в логических контекстах (условия `if`, циклы).

### Сводная таблица правил преобразования

| Исходное значение | Приведение к `Number()` | Приведение к `Boolean()` |
| :--- | :---: | :---: |
| `undefined` | `NaN` | `false` |
| `null` | `0` | `false` |
| `true` / `false` | `1` / `0` | не изменяется |
| Пустая строка `""` | `0` | `false` |
| Строка с пробелом `" "` | `0` (после удаления пробелов) | `true` (строка не пустая!) |
| Любая текстовая строка `"привет"` | `NaN` | `true` |

## 2. Базовые операторы, математика

Операторы делятся на **унарные** (принимают один операнд), **бинарные** (два операнда) и **тернарные** (три операнда).

* **Специфические операторы**:
  * Взятие остатка `%` (например, `5 % 2` вернет `1`).
  * Возведение в степень `**` (например, `2 ** 3` вернет `8`).

### Особенности бинарного плюса `+`
Если хотя бы один из операндов является строкой, то все остальные операнды принудительно приводятся к строке и конкатенируют (склеиваются):

```javascript
alert(2 + 2 + '1'); // "41" (сначала выполнится 2 + 2 = 4, затем 4 + '1')
alert('1' + 2 + 2); // "122" (сразу начнется конкатенация: '1' + 2 = '12')
```

### Инкремент (`++`) и декремент (`--`)
Изменяют значение переменной строго на единицу. Работают *только с переменными*.

* **Префиксная форма** (`++counter`): сначала изменяет переменную, затем возвращает **новое** значение.
* **Постфиксная форма** (`counter++`): сначала возвращает **старое** значение, а затем изменяет переменную.

## 3. Операторы сравнения

Все операторы сравнения возвращают логическое значение: `true` или `false`.

1. **Лексикографическое сравнение**: Строки сравниваются посимвольно в алфавитном порядке на основе кодировки Unicode.
2. **Приведение типов**: При сравнении значений разных типов JavaScript автоматически приводит их к числам.
3. **Нестрогое равенство (`==`)**: Сравнивает значения с приведением типов.
   * *Важное исключение:* Значения `null` и `undefined` равны друг другу при нестрогом равенстве (`null == undefined // true`), но не равны больше никакому другому значению в языке.
4. **Строгое равенство (`===`)**: Сравнивает значения **без** приведения типов. Если типы данных различаются, сразу возвращается `false`.

```javascript
alert( 0 == false );  // true (типы приведены к числам)
alert( 0 === false ); // false (разные типы данных)
```

> ⚠️ **Важно помнить:** Значение `NaN` уникально тем, что оно не равно абсолютно ничему, включая самого себя (`NaN === NaN` вернет `false`). Для его проверки используется функция `isNaN()`.

## 4. Условное ветвление: if, '?'

### Конструкция `if / else`
Инструкция `if (...)` вычисляет выражение в скобках и приводит его к логическому типу (`Boolean`).

```javascript
let year = 2026;

if (year < 2026) {
  alert('Это уже прошлое');
} else if (year > 2026) {
  alert('Это слишком далеко в будущем');
} else {
  alert('Вы угадали текущий год!');
}
```

### Тернарный оператор (знак вопроса) `?`
Используется для сокращения записи, когда нужно присвоить переменной одно из двух значений в зависимости от условия.

* **Синтаксис**: `let результат = условие ? значение_1 : значение_2;`

## 5. Логические операторы

Логические операторы в JavaScript работают по принципу *«короткого замыкания»* и возвращают **само значение операнда**, на котором остановилось вычисление.

* **`||` (ИЛИ)**: Ищет и возвращает **первое истинное (`truthy`)** значение. Если все ложные — возвращает последнее.
  ```javascript
  alert( "" || 0 || "Успех" || false ); // "Успех"
  ```
* **`&&` (И)**: Ищет и возвращает **первое ложное (`falsy`)** значение. Если все истинные — возвращает последнее.
  ```javascript
  alert( 1 && "Текст" && null && 5 ); // null
  ```
* **`!` (НЕ)**: Сначала приводит операнд к логическому типу, а затем меняет его на противоположный.

## 6. Операторы нулевого слияния и присваивания: '??', '??='

### Оператор нулевого слияния `??`
Возвращает первый операнд, если он определен. Если первый операнд равен `null` или `undefined`, возвращается второй операнд.

**Главное отличие `??` от `||`:**
* Оператор `||` считает ложными (`falsy`) любые пустые значения (`0`, `""`, `false`, `null`, `undefined`).
* Оператор `??` проверяет значения **только** на `null` или `undefined`.

```javascript
let count = 0;

alert(count || 10); // 10 (так как 0 — это falsy для оператора ИЛИ)
alert(count ?? 10); // 0 (так как 0 — это вполне определенное значение для ??)
```

### Оператор присваивания нулевого слияния `??=`
Записывает значение в переменную только в том случае, если текущее значение переменной является «пустым» (`null` или `undefined`).

```javascript
let userName;
userName ??= "Гость"; 
alert(userName); // "Гость" (значение присвоилось)

let userAge = 18;
userAge ??= 25; 
alert(userAge); // 18 (значение не изменилось, так как 18 определено)
```

## 7. Отправка изменений в Git

После того как файл конспекта (например, `README.md` или `js-basics.md`) создан и сохранен, выполните последовательность команд в терминале для сохранения изменений в репозиторий:

1. **Проверить статус репозитория**:
   ```bash
   git status
   ```
2. **Добавить файл в индекс отслеживания**:
   ```bash
   git add js-basics.md
   ```
   *(Или `git add .` чтобы добавить все измененные файлы)*
3. **Зафиксировать изменения (коммит)**:
   ```bash
   git commit -m "docs: добавить структурированный конспект по основам JS"
   ```
4. **Отправить изменения на удаленный сервер (GitHub/GitLab)**:
   ```bash
   git push origin main
   ```
